# 判定の枠組み: 各都道府県の観光スポットで、国または自治体が紹介している YouTube 動画をマーカーとして登録する

- 日付: 2026-10-24
- タスク: T127

## 目的と良い動作

- 地図を開くと、47 都道府県のどこにも、国や自治体が自ら紹介している観光スポットの動画のマーカーがある（利用者の依頼）。
- 1 本の動画は 1 つの観光スポットに置かれ、マーカーを押すとその場所の動画が地図の上で再生できる。
- 「公式」と言える根拠（国・自治体の公式サイトのどのページか）を、1 件ずつ後から確かめられる。

## 判定基準

| # | 基準 | 測り方 | 根拠 |
|---|---|---|---|
| C1 | 47 都道府県のすべてにマーカーがあり、件数は固定しない | 都道府県ごとの件数が 47 県すべてで 1 以上。基準を満たす候補は全件登録し、外した候補は理由を表に残す | 利用者 |
| C2 | どの動画にも「公式」の根拠がある | 全行に、国・自治体の公式サイトのページ URL があり、動画かチャンネルを載せている（100%）。団体の動画は自治体のページが紹介していること | 利用者・資料 4 |
| C3 | どの動画も 1 つの観光スポットを映している | 調査表の全行にスポット名がある。都道府県全体の PR 動画は 0 件（人が見る項目） | 利用者 |
| C4 | どの動画も Loca の地図の上で再生できる | 登録の直前の oEmbed が全件 200（埋め込みの禁止・非公開・削除は除く） | 資料 2 |
| C5 | 座標がスポットの都道府県の中にある | 調査の記録の項目の座標（出典か台帳）だけを使う。要確認は人が地図で確かめた印がある（100%） | 資料 5・地域の調査の設計書 |
| C6 | （取り下げ）Nominatim の規約 | 位置を調査の記録から決めるので呼ばない（2026-10-30） | 資料 1 |
| C7 | YouTube の画面を自動で読まない | 動画 ID の出どころは公式サイトのページと oEmbed と Data API（Actions）だけ。YouTube のページを取得したのは 0 回 | 資料 2・3 |
| C8 | 既存のマーカーと重複しない | 登録前の `videos/{videoId}` の確認で既存 0 件 | 資料 5 |
| C9 | 必須のタグを人が確定している | 全件に映っているもの・雰囲気があり、登録の窓で利用者が選んだ（案を入れない。ADR 0036） | 利用者・資料 5 |
| C12 | 投稿者は運営（2026-10-30 に改めた。ADR 0036） | 全件の `ownerUid` が `loca-official` で、`official` に提供元と根拠のページがある | 利用者 |
| C10 | 書いた文書がルールの形を満たす | REST で書いた文書に管理者の通常の更新が通る（`tests/rules/surveyMarker.test.mjs`）。本番の件数が調査の記録の登録済みと一致する（`npm run fs:read`） | 資料 5 |
| C11 | 公開後に地図に出る | `/ui-check` で 47 都道府県のマーカーが出て、件数が調査表と一致する | 利用者 |

# Loca 要件定義 (2) UI/UX・機能要件

> 移植元: Loca システム要件定義書 2章。

## 2. UI/UX・機能要件

### 2.1. サイトタイトル
* **タイトル**: ホームページおよびブラウザのタブに表示されるサイトタイトルは「**Loca**」とする。

### 2.2. 言語対応
* **既定の言語**: 日本語とする。
* **自動切り替え**: ブラウザで使用している言語を取得し、**英語（English）**であれば英語の表記に対応する。

### 2.3. サイドメニュー構成
* サイドメニューには以下のタブを**アイコン付き**で実装し、言語が理解できなくてもアイコンで何のタブであるか理解できるようにする。
    * 地図
    * 地域別ランキング
    * ~~チャネルランキング~~（2026-09-26 廃止。ユーザーのタブに置き換え。今のタブは下の「サイト名」の節の一覧。ADR 0031）
    * 機器別ランキング
* **サイドメニューの表示仕様**:
    * 通常時は画面左端に配置される。
    * サイドメニュー本体は地図の上に**オーバーレイ（重なって表示）**される形式とする。
* **共通結果パネル（検索・ランキング結果）の表示仕様**:
    * **表示領域**: マーカー検索およびランキングのフィルタ実行結果は、サイドメニュー内ではなく、地図エリア上に**オーバーレイ（Results Panel）**として表示する。
    * **動的な位置調整（レスポンシブ）**:
        * パネルの表示開始位置（X座標）は、**サイドメニューのトグル開始位置（サイドメニュー右端）から10pxの間隔**を空けて配置する。
        * サイドメニューの開閉（幅の増減）に自動的に連動し、パネルの表示領域全体がスライドして移動する仕様とする。
        * 上端は 16px。パネルの右端が右上のアカウントのボタンに届く幅（スマホ幅など）では、ボタンの下の 64px に下げる（閉じるボタンが隠れて押せなかった。2026-09-26・T94）。
    * **閉じる機能**: パネル（一覧）の**右上に「閉じるボタン（アイコン）」**を実装し、ユーザーが任意で結果一覧を非表示にできるようにする。

### 2.4. サイドメニューの開閉アイコンの統一
* **閉じるアイコンの配置**: サイドメニューが開いている状態での「閉じる」アイコンは、サイドメニュー内の**視認性の高い位置**（例：サイドメニューの最上部、または地図などのタブの行の隣）に移動させる。
* **アイコンのサイズ統一**:
    * サイドメニューを**閉じるアイコン**のサイズは、「地図」「地域別ランキング」などの**メインのタブアイコンと同一のサイズ**とする。
    * サイドメニューが閉じている状態（非表示時）で、メニューを**開くためのアイコン**（アイコン列の一番上。開くと横にサイト名が出る。ADR 0027）のサイズも、**メインのタブアイコンと同一のサイズ**とし、UI全体での**大きさの視覚的な一貫性**を持たせる。

### 2.5. プロフィール登録画面の項目と同意事項

#### 2.5.1. 入力項目（必須）

| 項目名 | 形式 | 選択肢/特記事項 | 必須性 |
| :--- | :--- | :--- | :--- |
| **国籍** | プルダウン | **日本、日本以外** | 必須 |
| **生年月日** | 日付入力 | 満年齢の確認のため。 | 必須 |
| **性別** | ラジオボタン | **男性、女性** | 必須 |

#### 2.5.2. 利用規約・同意事項（チェックボックス形式）

デフォルトでは**両方のチェックボックスが選択されていない状態**とする。

| ID | 項目名 | 選択方法 | 同意文章（法令遵守表現） |
| :--- | :--- | :--- | :--- |
| **同意 1** | **コンテンツ利用に関する同意** | チェックボックス | 本サイトに登録するYouTube URLは、**お客様ご自身が制作し、正当な権利（著作権等）を保有するコンテンツ**であること、および**第三者が制作した動画ではないこと**を確認し、これに同意します。 |
| **同意 2** | **個人情報等の取得目的** | チェックボックス | 本サイトが、お客様の個人情報（国籍、生年月日、性別）および登録された動画関連情報を、以下の目的のために取得・利用することに同意します。<br>・Google Maps API等の**外部APIを使用した地図上のマーカー表示および関連情報の収集**<br>・**本サイトの利用状況に関する統計情報**の作成、分析、改善。 |

#### 2.5.3. 登録ボタンの制御

* 上記の**「コンテンツ利用に関する同意」**および**「個人情報等の取得目的」**の**両方のチェックボックスが選択されるまで**、「登録」ボタンは**非活性化（グレーアウト）**とする。

### 2.6. プロフィール画面（認証済みユーザー）の機能

* **UI要素の追加**: Google認証アイコンクリック時のポップアップに、既存の「ログアウト」の下に**「プロフィール」**の項目を追加する。
* **プロフィール画面の表示**:
    * **編集可能項目**: **国籍**と**性別**の2項目のみ**変更可能**な状態で表示する。
    * **編集不可項目**: その他の登録項目（生年月日など）は**編集不可**の状態で表示する。
    * **登録日の表示**: Google認証を初めて実行した日付を**「登録日」**として表示する。
* **操作ボタン**: プロフィールの編集画面には、**「更新」**、**「キャンセル」**、**「削除」**の3つのボタンを実装する。

### 2.7. ユーザーアカウントおよびマーカー情報の削除フロー

* **目的**: 個人情報保護法を遵守する。
* **統合ポップアップの表示**: 「削除」ボタンをクリックした場合、以下の統合ポップアップを表示し、ユーザーに最終確認を求める。
* **統合ポップアップの内容**:

【最終確認】アカウントおよびデータの完全削除 この操作は元に戻すことができません。

お客様のプライバシー保護を目的として、当サイトから以下のすべての情報が永続的に削除されます。 お客様のプロフィール情報: 登録日、国籍、性別、生年月日、および同意に関する記録。 お客様が登録されたすべてのマーカー情報: 地図上に登録されたYoutube URL、位置情報、タグ、現地メモ、撮影機器情報など、お客様のアカウントに紐づく全てのデータ。

【重要】 アカウント削除後、当サイトで新たにマーカーを登録したい場合や、特定の機能を利用したい場合は、再度Google認証を行い、新しいプロフィール登録と全ての同意手続きが必要になります。 この操作を実行すると、お客様のGoogleアカウントは当サイトの利用登録履歴から削除され、復元することはできません。 上記の内容を理解し、アカウントと関連する全データの削除を永続的に実行することに同意しますか？

[キャンセル] [アカウントを削除する]

* **削除実行後の挙動**:
    * 「アカウントを削除する」が選択された場合、該当ユーザーの**すべてのマーカー情報**と**プロフィール登録情報**（アクセス履歴を含む）を削除する。
    * 次回のGoogle認証時は、ユーザーは未登録ユーザーとして扱われ、**プロフィール登録画面が再表示される**。

### 2.8. 地図フィルタ（2026-09-24 追加。ADR 0015）

マーカーが増えても地図が見えるよう、地図に出すマーカーを絞る。どの画面でも画面下に常設する。

| 項目 | 仕様 |
|---|---|
| 置き場所 | 地図の下端（出典表示の帯の上）。左端はサイドメニューと結果パネルの右、右端はズームボタンの列を空ける |
| 画面下 | 「フィルター」ボタン 1 つだけ（どの画面幅でも。2026-09-24 変更）。有効な条件の数をボタンに出す |
| 「フィルター」 | ボタンの上にパネルを開く。表示するもの（動画・撮影リクエスト）、雰囲気（マーカーと同じ色の印で凡例を兼ねる）・映っているもの・撮影の季節・撮影の時間帯・撮り方・機器の分類（動画だけに効く）を選ぶ。「条件をクリア」で初期状態に戻す。Esc で閉じる |
| 反映 | 変更はすぐ地図に反映する（「適用」ボタンは無い）。同じ項目の中は OR、項目の間は AND（要件 4.2 と同じ） |
| 撮影リクエスト | 季節・時間帯・撮り方だけが効く。条件に合うリクエストだけで熱量を数え直して表示する |
| 効く範囲 | 地図のマーカーと、範囲指定検索（3.1.3）の結果。キーワード検索とランキングは自分の条件を持つ |
| 隠すとき | 登録・編集の途中（仮マーカーの表示中）と、置く幅が 140px 未満になるとき（スマホでサイドメニューや結果パネルを開いたとき） |
| 部品の大きさ | ボタンも選択チップも、ほかの操作部品と同じ 36px（h-9）。選択チップは等幅の格子に並べる（サイドメニュー・登録フォームも同じ） |
| URL（T42） | 条件と選んだマーカーを URL のクエリに映す（例 `?mood=calm,grand&eq=drone&requests=0&m=<ID>`。既定の項目は載せない）。その URL を開くと同じ条件と同じマーカーで始まる。知らない値は読み飛ばす。マーカーの「共有」はこの URL をコピーする（2026-09-25 から。以前は YouTube の URL）。撮影リクエストも同じで、地点の位置を `r=<緯度>,<経度>`（小数 6 桁）で載せ、開くとその地点を選ぶ（T84。地点の ID は同期で変わりうるので位置で指す。マーカーと両方あればマーカーを優先） |

## 追記（2026-09-25 サイドメニュー上部のサイト名。ADR 0026・0027・T79）

サイト名を覚えてもらうため、2.3 のサイドメニューに次を足した。常設のタイトルバーは地図の操作の場所を狭めるので置かない。

- サイドメニューを開くと、上部に「Loca │ メニュー名」を 1 行で出す。閉じると出ない。メニュー名は今までどおり残す。
- 「Loca」は押せない文字で、書体は Fraunces（ADR 0026）。高さ・色・スマホでの切り方は ADR 0027。
- 今のタブは 7 つ（最近・投稿・検索・ユーザー・撮影リクエスト・地域・機器）。チャンネルのタブはユーザーのタブに置き換えた（2026-09-26。ADR 0031）。定義は `src/features/sidebar/TabRail.tsx` の `TAB_ICONS`。

## 追記（2026-10-02 最近のアクティビティ。ADR 0034・T80）

- 「最近」のタブは、新しい動画と撮影リクエストを新しい順に 20 件出す。行を押すと地図がその場所へ寄り、情報を開く。
  いいねは出さず、撮影リクエストは依頼した人を出さない（場所と熱量だけ）。

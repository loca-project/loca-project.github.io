# 動画の読み取りの指示書（第 2 版）

YouTube の照合の読み取りの段で読み手に渡す指示。結果は [21-youtube-matching-review.md](21-youtube-matching-review.md)。

依頼で指定された束のファイルに、鹿児島県の自治体などの公式 YouTube チャンネルの動画があります。1 本は `#番号 [チャンネル／持ち主]`、`題:` 題名、`文:` 説明文の 3 行です。全部を読んで、1 本ずつ判定してください。

目的は、**地図に置いて旅行者に紹介できる、観光の場所の動画**を見つけることです。

## 判定すること

- `kind`（どれか 1 つ）
  - `place`: 主題が 1 つの特定の**観光で訪れる場所**で、その場所を映す、または紹介する動画。滝・岬・海岸・山・島の中の名所・神社や寺・史跡・公園・展望所・灯台・水族館や動物園や博物館など、誰でも訪れられて、地図の 1 点に置ける場所
  - `event_at_place`: 主題は祭りや行事だが、1 つの特定の場所で行われている動画
  - `area`: 主題が地区・島全体・市町村など面の広がり（地図の 1 点に置けない）
  - `multi`: 複数の場所を巡る、並べる、紹介する動画
  - `other`: 上のどれでもない
- 次は `place` にせず、`other` にする。
  - 保育園・こども園・学校・福祉や子育ての施設・役所など、旅行者が訪れる場所でないもの
  - 企業・工場・農家・個人の店や飲食店の紹介
  - 港・空港・駅などの紹介でも、物流や仕事の話が主題のもの（駅舎そのものが見どころの動画は `place`）
  - 題名の場所の名前が、行事や人物の話の舞台として出るだけのもの
- `place`: `kind` が `place` か `event_at_place` のときの、場所の名前。**題名か説明文に書かれているとおりに**書く。それ以外は空文字
- `quote`: その場所の名前を含む、題名か説明文からの抜き書き（そのまま 40 字以内）。それ以外は空文字
- `sure`: 読み取りに自信があれば `high`、題名だけで推測に近ければ `low`

## 決まり

- 書かれていないことを推し量らない。題名と説明文だけで決める。迷ったら `other` か `sure: low` にする。
- 自分の知識で場所の名前を補わない。
- 1 つの島や地区でも、題名が特定の地点の名前（例: 〇〇崎、〇〇の滝、〇〇大島のような名所）なら `place` にしてよい。

## 出力

依頼で指定された出力先に、次の形の JSON を Write ツールで書いてください。束のすべての動画を、番号の順に入れます。`i` はファイルの `#番号` そのままです。

```json
[{ "i": 0, "kind": "other", "place": "", "quote": "", "sure": "high" }]
```

ファイルは Read の offset と limit で分けて読めます（750 行）。このファイルと束のファイルのほかは読まないでください。

書いたら依頼で指定された検査を実行し、違反 0 件になるまで結果を直してください。値を作らず、直せないものは `other` にします。

終わったら、件数と検査の結果の 1 行、`other` に直した番号だけを返してください。

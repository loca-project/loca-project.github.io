# 0038. ランキングは Loca のデータだけで数え、再生数を合計しない

- 日付: 2026-11-01
- 状態: 採用（利用者「規約に違反する対象のランキングは廃止とします」「登録件数は残します」「公式の紹介はランキングから除外して下さい」）
- タスク: T156。関連: [0017](0017-YouTube-Data-APIとFirestoreへの書き込みはActionsから行う.md)、[0031](0031-人のタブは公開データの投稿者だけを探しチャンネル別ランキングを置き換える.md)、[0036](0036-公式の動画は運営が紹介する別枠にする.md)

## 背景

地域別・機器別ランキングとユーザーのタブは、YouTube Data API の再生数を合計して順位を付けていた。
YouTube API Services Developer Policies（更新日 2026-10-15）は次を定める。

| 条項 | 原文の要点 |
|---|---|
| III.E.2 | "Do not aggregate API Data"。例外は同じコンテンツ所有者のチャンネルで、その所有者だけが見る場合 |
| III.E.4.h | API Data から "new or derived data or metrics" を作らない。例として総再生数などを組み合わせたスコアを挙げる |

Loca の合計は複数の投稿者にまたがり、誰でも見られるので、例外に当たらない。文言の読み方であり、法的な見解や YouTube の確認は得ていない。

## 決定

1. **再生数の合計を廃止する。** 地域別・機器別の基準と表示、ユーザーのタブのソート順・表示・同点時の並びから外す。
2. **地域別・機器別は Loca の登録件数で並べる。** 同じなら新しく登録した順。
3. **ユーザーのタブは投稿数・いいね・撮影リクエストの 3 つにする。** 同じなら投稿数、さらに新しい順。
4. **公式の紹介はランキングから除く**（ADR 0036 の決定 4 を改める）。検索と地図には出る。
5. **動画ごとの再生数の表示は残す。** API の値をそのまま出すだけで、集計でも新しい指標でもない（III.E.4.f）。毎晩の取得も続ける。

## 結果

- 登録件数は、1 人が大量に投稿すると順位が歪む（ADR 0006 の弱点）。利用者の判断は、歪みは別の指標への切り替えで避けられるので残す、である。
  切り替えがあるのは今はユーザーのタブだけで、地域別・機器別には無い。足すかは T158 で聞く。
- 公開の順位が変わる。件数の数え方は `tests/core/ranking.test.mjs` が確かめる。

## 採らなかった案

- **再生数の合計を残す**: 条文に反すると読めるので、利用者の判断で廃止。
- **公式の紹介を地域別に残す**: 運営の登録数で順位が動く。利用者の判断で除外。
- **1 本ごとの再生数の順位を新しく作る**: 合計ではないが、禁止かどうかを原文から断定できない。作らない。

## 未判断（T158）

動画の投稿日と長さでの順位の絞り込み、Loca のいいねと YouTube の値を並べた表示、動画から読み取った場所の名前の 3 つが条文に当たるかは、ここでは決めていない。

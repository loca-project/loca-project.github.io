# 0035. 調査のページからオーナーの権限でマーカーを登録・削除する

- 日付: 2026-10-30
- 状態: 採用
- タスク: T132（利用者の依頼「各タブに公開ページへのマーカーの登録と、登録されていたら削除のボタンを追加」）

## 背景

地域の調査（`survey/`。公開しないページ、`http://localhost:5180`）で見つけた公式の動画を、公開サイトのマーカーにしたい。
書き込みの経路は 2 つある。

| 経路 | 利点 | 欠点 |
|---|---|---|
| A. この PC のサーバーがオーナーの権限（Firebase CLI のログイン）で REST を呼ぶ | 既存の管理用スクリプトと同じ経路（`lib/owner-auth.mjs`）。追加の設定が要らない。ページでログインしない | ルールを通らないので、形を別に確かめる必要がある |
| B. ページに Firebase SDK を入れて利用者がログインする | ルールが守る | ブラウザ用のキーの許可にポート 5180 を足す（ADR 0030）。別のポートでログインし直す。6 秒に 1 件の間隔がかかる |

## 決定

1. **A を採る。** 書くのは、ページで利用者が「登録する」「削除」を押したときだけ。
2. **形はサイトの書き込みと同じにする。** `scripts/lib/survey-marker.mjs` が作る項目がルールの作成を通ることを、`tests/rules/surveyMarker.test.mjs` が確かめる。
3. **タグは利用者がページで選ぶ。** 案を先に入れない（ADR 0014 決定 7）。撮影機器は分からないので未選択（空文字）にする。
4. **位置と動画はページから受け取らない。** サーバーが調査の記録（`items.json`・`matches.json`）の行から決める。題名などは登録の直前の oEmbed の値で、埋め込めない動画は書かない。
5. **削除はサイトと同じ論理削除**（`deleted` と `updatedAt` を変え、動画の索引を外す）。消せるのは CLI のアカウントが登録したものだけ。
6. **サーバーはこの PC のページからの呼び出しだけを受ける**（Host と Origin を確かめる）。別のサイトから本番を書かせないため。
7. 投稿者は CLI のアカウントの Loca のプロフィール（`ownerUid`・ニックネーム）。

（追記 2026-10-30）決定 2・5・7 は ADR 0036 で改めた。`official` 付きの作成はルールが拒むので、形の確かめは「REST で書いた文書に管理者の通常の更新が通る」ことで行う。投稿者は運営（`loca-official`）になり、消せるのは公式の紹介だけ、削除は「載せない」の判断として記録する。

## 影響

- レートリミット（6 秒に 1 件）の対象外になる。押した分だけ書くので、一括の登録はしない。
- 公開サイトには `updatedAt` の差分の購読ですぐに出る。翌晩の同期で公開データに入る。
- `survey/` は公開しないので、この窓口は公開物に含まれない（`survey-marker.mjs` だけがリポジトリにある）。

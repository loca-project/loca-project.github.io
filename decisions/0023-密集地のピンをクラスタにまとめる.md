# 0023. 密集地のピンをクラスタにまとめる

- 状態: 採用
- 日付: 2026-09-25
- 関連: [0011](0011-地図と地名を国土地理院に統一する.md)、[0015](0015-地図フィルタを画面下に常設する.md)

## 背景

ピンは 1 本ずつ DOM の Marker で置いていた。件数が数千になると地図の操作が重くなり、
日本全体を見る倍率では関西・首都圏のピンが重なって押し分けられなかった。
ADR 0015 は、見たいものを選ぶ地図フィルタと、数の多い地域をまとめるクラスタを併用するとしていた。

## 決定

1. どのピンをまとめるかは、MapLibre の GeoJSON ソースの `cluster` に計算させる（`src/adapters/map/pinLayer.ts`）。
   - まとめる距離は 32px（ピンの幅）。重ならないピンはまとめない。
   - ズーム 15 より寄ったらまとめない（同じ建物の複数の動画を押し分けられるように）。
   - 動画と撮影リクエストを同じソースに入れ、まとめて数える。
2. **描画は DOM の要素のままにする。** 画面に置くのは、読み込まれたタイルにある点とクラスタだけ（2000 件で 8 個）。
   地図のスタイルに文字のグリフが無く、シンボルのレイヤーでは件数の数字を描けないため。
   ピンの見た目（雰囲気の色・撮影リクエストの熱量）はこれまでと同じ。
3. クラスタは白地に濃い枠と件数。撮影リクエストのピン（濃い地に白い数字）と見分けられるようにする。
   押すと `getClusterExpansionZoom` の倍率まで寄る。
4. `MapPort.setPins` の形は変えない。アダプタの中だけで切り替える。

## 検討した代替案

- **円とシンボルのレイヤーで描く**: いちばん軽いが、件数の数字と熱量のラベルにグリフの配信元が要る。
  国土地理院のタイルだけで完結させる方針（ADR 0011）から外れるため却下。
- **DOM の Marker を全件置いたまま、重なりだけをまとめる**: 件数に比例して重くなる問題が残る。却下。

## 確かめ方

`node tools/ui-check/run.mjs project/tests/ui/cluster.check.mjs --seed-count 2000`
（件数の合計・DOM の数・寄り引きのフレーム間隔・クラスタを押すと広がる・ピンを押すと開く。2026-09-25 に 7 / 7 件 OK）。
画面の確認では、ピンの数を `.loca-pin` ではなく `ui.shown()`（ピン＋クラスタの中身）で数える。

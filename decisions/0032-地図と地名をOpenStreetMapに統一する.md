# 0032. 地図と地名を OpenStreetMap に統一する

- 状態: 採用
- 日付: 2026-09-26
- 置き換え: [0011](0011-地図と地名を国土地理院に統一する.md)（地図タイル・逆ジオコーディング・地名検索のすべて）
- 関連: [0003](0003-地図エンジンは-MapLibre-を既定にする.md)（MapLibre は継続）、[0010](0010-書き込みと認証にFirebase無料プランを使う.md)（請求先を前提にしない）

## 背景

2026-09-26、国土地理院の住所検索（`msearch.gsi.go.jp`）が、接続だけ受けて応答しない状態になった。
逆ジオコーダ・地理院タイル・市町村コード表は応答していた。Loca の検索ボタンは「確認中」のまま戻らなくなった
（待ち時間の上限を付けて直した。T96）。

ADR 0011 のとおり、住所検索と逆ジオコーダは地理院地図のための非公式の API で、予備を持たない決まりだった。
利用者の依頼で、商用利用できて無料で、可用性の高い仕組みを一から比べ直した。

| 方式 | 商用利用 | 料金・登録 | 可用性 | 英語 |
|---|---|---|---|---|
| 国土地理院（ADR 0011） | 外部からの利用について規約に記載なし | 無料・キー不要 | 保証なし。当日停止 | ✗ |
| OSM の公開サーバー（タイル・Nominatim） | 規約の条件を守れば可 | 無料・キー不要 | 保証なし（best-effort） | ○ |
| Geoapify 無料プラン | 可 | 1 日 3,000 回・キーをブラウザに配る | 回数を超えると失敗 | ○ |
| MapTiler 無料プラン | 非商用のみ | 月 1,000 回 | 超えると月末まで停止 | ○ |
| Photon の公開版 | 妥当な量なら可 | 無料 | 保証なし | ○ |
| オープンデータから検索用データを作り GitHub Pages に置く | 出典の表記で可 | 無料 | サイトと同じ | ○ |

地理院地図の「地名検索」は、住所検索と同じ URL だった（地理院地図の `js/setting.js` の `CHIMEI_SEARCH`）。
別の窓口は無く、国土地理院のままでは停止を避けられない。

### Nominatim の実測（2026-09-26、1 秒に 1 回以下・アプリを名乗って実行）

| 確認 | 結果 |
|---|---|
| 地名検索 日本語 15 問（東京タワー・嵐山・丸の内 1 丁目など。5 km 以内なら正解） | 15 / 15 |
| 地名検索 英語 10 問（Tokyo Tower・Kinkaku-ji など） | 10 / 10 |
| 応答の中央値 | 956 ms |
| 逆ジオコーディング 5 地点（東京タワー・京都駅・札幌駅・那覇・富士山頂） | 4 / 5。東京だけ `province` が空。`ISO3166-2-lvl4`（`JP-13`）から引けば 5 / 5 |

## 決定

**地図タイル・地名検索・逆ジオコーディングを、すべて OpenStreetMap の公開サーバーにする。予備の実装は持たない。**
OSM 財団の利用規約（タイル・Nominatim）を、次のように守る。

| 規約 | 守り方 | 担保 |
|---|---|---|
| タイルは `https://tile.openstreetmap.org/{z}/{x}/{y}.png` をそのまま使う | `maplibreStyle.ts` の `osmStyle` | verify が URL を検査 |
| 地図の右下に出典を出す | 「© OpenStreetMap contributors」（copyright ページへのリンク） | verify が検査 |
| Web ページは Referer を送る。止める設定をしない | `index.html` に Referrer-Policy を置かない | verify が `no-referrer` を検査 |
| タイルは HTTP の指示どおりキャッシュし、no-cache を送らない。先読み・保存をしない | ブラウザの HTTP キャッシュに任せる。見ている範囲だけを読む | [宣言] |
| 地名検索は利用者の操作で呼ぶ。入力途中の候補表示をしない | 検索ボタン・Enter のときだけ呼ぶ | [宣言] |
| 全利用者の合計で 1 秒に 1 回まで | この端末からは 1.1 秒以上あけて 1 件ずつ呼ぶ | テスト（`nominatimGeocode.test.mjs`） |
| 結果はこちら側でキャッシュする（同じ問い合わせを繰り返すと止められる） | 検索語（正規化）と地点（小数 4 桁）でブラウザに 300 件まで保存。見つからなかった語も覚える | テスト |
| 定期的に動くスクリプトは 1 分に 4 回まで | 同期（`enrich.mjs`）は 15 秒おき・1 回 8 件まで。1 回の同期の中では同じ地点を問い合わせない（海上など地名が空のままの行は、同期のたびに問い合わせ直す） | [宣言] |
| アプリを名乗る | 同期は `User-Agent: Loca/…` を送る。ブラウザは Referer で名乗る | [宣言] |

1. 地名 → 座標は `/search`（`countrycodes=jp`・`limit=1`）。日本語・英語の地名とも引ける。
   ADR 0011 の候補の選び方（`pickSearchHit`）と市町村コード表は要らなくなったので消した。
2. 座標 → 地名は `/reverse`（`zoom=10`・`accept-language=ja`）。都道府県は `ISO3166-2-lvl4`（`JP-13`）の数字から引き、
   無ければ `province`・`state` を都道府県の一覧と照合する。市区町村は `city`・`town`・`village` の順
   （政令指定都市は市、東京 23 区は区）。
3. 応答を待つのは 10 秒まで（T96 と同じ）。応答しないときは「見つからない」と分けて伝える。
4. 地名の出典の値（`PlaceMeta.source`）は `osm`。保存はしていない。

## 検討した代替案

- **国土地理院に地理院地図と同じ指定（`lang=ja,en`・`sort_il=1` など）を足して使い続ける**:
  英語と並び順は良くなる見込みだが、停止した API そのものは変わらない。外部からの利用の可否も規約に無い。却下。
- **オープンデータ（アドレス・ベース・レジストリ・OSM の抜き出し）から検索用データを作り、GitHub Pages に置く**:
  可用性は最も高い。表記ゆれの吸収と候補の並べ方を自作し、月ごとの取り込みを保守する手間がかかる。
  利用者が、OSM の規約を守るだけの簡素な構成を選んだ。OSM が止まったとき・利用者が増えて 1 秒 1 回を超えるときの移行先として残す。
- **地名検索だけ OSM にし、タイルは地理院のまま**: 見た目は変わらないが、提供元が 2 つに分かれる（ADR 0011 が避けた形）。却下。
- **Geoapify の無料プラン**: 商用可だが、1 日 3,000 回の上限とキーの配布があり、私企業に依存する。却下。

ADR 0011 は Nominatim を「提供元が 2 つに分かれる」「1 秒 1 回の制限」「市町村の返し方が地域でばらつく」の理由で却下していた。
1 つ目はタイルも OSM にして解消した。2 つ目と 3 つ目は下の「悪くなること」に残る。

## 結果

良くなること:

- 地図と地名の提供元が OSM 財団の 1 つになり、守る規約も 1 つにまとまった。API キーも請求先も要らない。
- 英語の地名で検索できる（日本語 15 / 15・英語 10 / 10）。
- 候補の選び方の工夫（`pickSearchHit`）と市町村コード表（`muni.js`）が要らなくなった。
- 同じ語・同じ地点は 2 回目から問い合わせない（キャッシュ）。

悪くなること:

- **稼働の保証（SLA）が無いのは国土地理院と同じ。** OSM が止まると、地図と地名検索が同時に使えなくなる。予備は無い。
- **地名検索は全利用者の合計で 1 秒に 1 回まで。** 利用者が増えたら、自前の検索用データ（上の代替案）への移行が要る。
- **市区町村の判定は、県境・市境の近くで国土地理院より不正確になりうる**（未確認。確かめたのは 5 地点だけ）。
- **マーカーの見分けやすさが下がった。** OSM の水面（`#AAD3DF`）とのコントラスト比が、賑やか 1.87・懐かしい 1.72 と 2 を下回る
  （淡色地図では全色 2 以上だった。2026-09-26 にタイルから実測）。
  → 2026-10-02 に 6 色を選び直し（全色 2 以上）、縁取りを濃い灰にした（T98・ADR 0014 の追記）。
- 過去の調査（`references/10-free-hosting-candidates.md`、2026-09-22）は「OSM の公式タイルは公開用途では規約違反」としていたが、
  今の規約に埋め込みを禁じる文は無い（禁止は先読み・まとめての取得・オフライン用の保存）。調査の文書に追記した。
- 地図の見た目が、淡色の地理院地図から色の多い OSM の標準の地図に変わった。地図の文字は日本語のまま
  （英語で出すにはベクトルタイルと自前のスタイルが要る）。

## 確かめ方

- `npm run check` の `tests/core/nominatimGeocode.test.mjs`（間隔・キャッシュ・待ち時間の上限・都道府県の取り出し。10 件）と、
  verify の「地図と地名の使い方が OpenStreetMap の規約どおり」。
- 実ブラウザ（`/ui-check`）で、OSM のタイル 40 枚・国土地理院への要求 0 件・出典の表示・Referer・
  日本語と英語の地名検索・同じ語の 2 回目は問い合わせ 0 件・見つからない語の通知の 8 / 8 件（2026-09-26）。

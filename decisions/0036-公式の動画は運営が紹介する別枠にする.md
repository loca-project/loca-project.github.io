# 0036. 公式の動画は、利用者の投稿と分けて運営が紹介する

- 日付: 2026-10-30
- 状態: 採用（利用者「推奨で進めてください」）
- タスク: T144。ADR 0035 の登録の経路を前提にする

## 背景

国や自治体の公式チャンネルの動画をマーカーにしたい（T127）。ところが、登録の仕組みだけを先に作ったところ、サイトの決まりと合わなかった。

| 場面 | 利用者の投稿の決まり | 公式の動画をそのまま入れると |
|---|---|---|
| 同意 | 「自分が撮影・制作し…第三者が制作した動画は登録しません」 | 正面から反する |
| 通報 | 理由の 1 番が「登録者本人以外の動画URLの登録」 | 全件が正当に通報できる |
| いいね | 投稿者への「ありがとう」（ADR 0024） | 感謝の宛先が違う |
| ユーザーのタブ | 投稿数・再生数・いいねの順（ADR 0031） | 自治体の再生数で管理者が上位に並ぶ |
| アカウント削除 | 本人の全マーカーを論理削除（ADR 0021） | 管理者を消すと公式の分も消える |

権利の面では、県の「南の宝箱 鹿児島チャンネル」の運用ポリシー（2026-10-30 に原文を確認）が、無断使用・無断転載を禁じる一方で、
「転載の対象となる発信情報を改変せず、また、出所を明記した配信動画等のシェア」は禁止されないと書いている。「鹿児島県公式チャンネル」のポリシーに転載の記載は無い。
市町村・国のチャンネルの条件は未確認。

## 決定

1. **公式の動画は「公式の紹介」とし、利用者の投稿と分ける。** 同意文は利用者の投稿にだけ適用する。文言は変えない。
2. **出所を必ず出す。** マーカーに `official: { provider, sourceUrl }`（提供元と、公式と確かめたページ）を持たせ、詳細に「公式の紹介」と提供元・根拠のリンクを出す。動画は埋め込みのままで改変しない。
   投稿者は運営（`ownerUid: loca-official`・`Loca 運営`。誰もログインできない）にし、一般の画面には投稿者の行とプロフィールへのリンクを出さない。撮影機器の行も出さない。管理者の画面は例外で、運営を投稿者として扱う（通報の画面は提供元を出す）。
3. **`official` は運営の経路だけが書く。** 利用者は作成でも更新でも付けられず、管理者も変えられない（ルールが守る）。管理者は論理削除できる。
4. **集計に入れない。** ユーザーのタブ（`summarizePosters`）と自分の投稿には出ない。いいねは押せるが投稿者の順位には数えない。検索には出る。ランキングは、地域別の合計の再生数には入り、撮影機器別には（機器が空なので）入らない。
   最近のアクティビティと RSS は投稿者ではなく提供元を出す。
5. **撮影リクエストと結び付けない。** `answers` を付けず、炎も付かない（ADR 0028 の「応える」は人の行為のまま）。
6. **登録できるのは、関連度「高」で、1 つの場所を映すと人が確かめた動画。**（関連度の決め方は ADR 0037 の決定 4） 要確認の位置は、地図で確かめた印が無いと登録できない（サーバーが拒む）。タグは人が選ぶ（ADR 0014 決定 7）。
7. **権利者への窓口は通報。** 公式の紹介では、通報の理由の「著作権侵害、または登録者本人以外の動画URLの登録」を「掲載の取り下げの依頼」に替える。
   持ち主が自分で投稿したいときは、管理者が公式の紹介を論理削除して動画の索引を外し、持ち主が投稿する。
8. **「載せない」は判断として残す。** 調査のページからの削除は理由を求め、`survey/<県>/youtube/decisions.json` に記録する。再調査で候補に戻さない（「戻す」で解除できる）。論理削除なのでいいねは戻らない。

   追記（2026-10-31。利用者）: 調査のページの表では隠さず、「載せない」と理由と「戻す」を出したまま残す。隠すのは列の絞り込みを選んだときだけ。
9. **根拠のページが無いチャンネルは登録しない。** 利用者が公式と認めたチャンネルでも、公式サイトのリンクを確かめられないものは、ページを記録するまで読み取りだけにとどめる（2026-10-31。利用者「推奨で進めてください」）。

## 採らなかった案

| 案 | 理由 |
|---|---|
| 管理者の投稿のまま入れる | 同意文に反し、集計と通報の意味が崩れる |
| 同意文を変えて第三者の動画を誰でも登録可にする | 権利の守りが弱まる。ADR 0014 の「他人の動画を確かめられない」問題が広がる |
| 近くの撮影リクエストに自動で応える | 依頼者の意図と違う動画が届く（ADR 0028） |

ADR 0029 の「本人のバッジを出さない」は、自己申告が本人確認として弱いという理由の決定で、運営が公式サイトのリンクで確かめた印とは別の話である。利用者の投稿には引き続きバッジを出さない。

## 影響

- ルールを変えるので、本番はコードより先に反映する。`official` の無い古いデータはそのまま動く。
- 公開データ（`markers.json`）に `official` が載る。
- 市町村と国のチャンネルの転載の条件は未確認。出所を明記する形で共通にそろえ、取り下げの依頼には応じる。

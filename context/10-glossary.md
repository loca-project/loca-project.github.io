# 用語集

| 用語 | 意味 | 備考 |
|---|---|---|
| Loca | このサイトの名称 | 移植元の「Chronos MAP」を改称したもの。コード・UI・文書すべてで Loca に統一する |
| マーカー | 地図上の 1 地点に紐づく YouTube 動画 1 本の登録 | `MarkerData`。UI の「ピン」と同じものを指す |
| 撮影リクエスト | まだ動画が無い地点への「撮ってほしい」という表明 | `RequestEntryData`。地点ごとの集計が `RequestMarkerData` |
| 熱量 | 撮影リクエスト 1 件の強さ（1〜5） | 1 利用者が保有できる合計も 5 まで |
| 受け取る | 依頼者が、自分の撮影リクエストに応えた動画を認めること | リクエストが閉じて熱量が戻る（ADR 0028） |
| 炎 | 受け取られた撮影リクエストの熱量を、応えた動画の側に貯めたもの | `answerCounts/{markerId}`。投稿者のプロフィールで合計を出す（T82） |
| 仮マーカー | 登録・編集の途中で地図に出るグレーのピン | タグによらず一律グレー（要件 3.2） |
| タグ | 投稿者が現地や映像を見て付ける情報。映っているもの・雰囲気（必須）、撮影の季節・時間帯・撮り方（任意） | 要件 3.3・ADR 0014。値は英小文字のキーで保存する |
| 雰囲気 | タグのうち、マーカー色を決めるもの | 賑やか／穏やか／幻想的／壮大／懐かしい／スリル |
| 現地メモ | 投稿者が書く 80 字までの自由記述 | タグではない。通報の対象 |
| 公式の紹介 | 国や自治体の公式チャンネルの動画を、運営が紹介するマーカー | `official`。利用者の投稿と分け、提供元を出す。投稿者の順位に数えない（ADR 0036） |
| 地図フィルタ | 画面下に常設する、地図に出すマーカーの絞り込み | ADR 0015。雰囲気のチップが凡例を兼ねる |
| 論理削除 | `deleted: true` を立てるだけの削除 | アカウント削除・管理者の削除も論理削除。物理削除は 30 日後に Actions が行う（ADR 0021） |
| 共通結果パネル | 検索・ランキングの結果を出す地図上のオーバーレイ | サイドメニューの開閉に連動して動く |
| ポート | 「何ができるか」を定義したインターフェース | `src/ports/` |
| アダプタ | ポートの具体的な実装 | `src/adapters/`。外部 SDK を import してよい唯一の場所 |
| 縮退運転 | 公開データ・地図タイル・差分の購読のどれかが読めず、欠けたまま動いている状態 | 画面上部の帯で知らせる（`HealthNotice`） |
| ベースデータ | `public/data/markers.json` | 日次バッチが生成する確定データ。可用性の一次ソース |

## 表記ゆれの統一

| 使う | 使わない |
|---|---|
| Loca | Chronos MAP、Chronos Map、ロカ |
| マーカー | ピン、マーカ、marker（文章中） |
| 撮影リクエスト | リクエストマーカー（型名を除く）、要望 |
| 論理削除 | ソフトデリート、非表示化 |
| サイドメニュー | サイドバー、左メニュー |
| アダプタ | アダプター |
| ユーザー | ユーザ、利用者（UI 文言を除く） |
| タグ | 感情タグ、感情の核（2026-09-24 に廃止） |
